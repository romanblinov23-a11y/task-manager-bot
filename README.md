# task-manager-bot

Telegram-бот — проджект-менеджер для трёх проектов (Парк Горького, Окко,
Аврора). Фиксирует задачи и договорённости из рабочих чатов, личных
сообщений и протоколов встреч, опрашивает сотрудников по статусам, ведёт
таблицы в Google Sheets и формирует ежедневную/мгновенную/еженедельную
отчётность.

Стек: Python, python-telegram-bot, Anthropic API (claude-sonnet-4-6),
Google Sheets API, APScheduler, Railway.

Подробная спецификация — см. [PROJECT_SPEC.md](PROJECT_SPEC.md).
