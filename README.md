# task-manager-bot

Telegram-бот с двумя блоками: трекер задач по проектам (фиксирует задачи и
договорённости из рабочих чатов, личных сообщений и протоколов встреч,
опрашивает сотрудников по статусам, формирует ежедневную/мгновенную/
еженедельную отчётность) и мониторинг конкурентов (еженедельные снятия,
ёмкость и доля рынка, дашборд). Проект и рынок — одна и та же сущность;
список проектов ведётся владельцем через `/add_project`, не хардкодится.

Хранилище: две отдельные SQLite-базы (`data/tasks.db` для задач,
`data/monitoring.db` для мониторинга) — общие только пользователи, по
telegram_user_id.

Стек: Python, python-telegram-bot, Anthropic API (claude-sonnet-4-6),
APScheduler, Railway.

Подробная спецификация — см. [PROJECT_SPEC.md](PROJECT_SPEC.md) (описывает
исходную архитектуру на Google Sheets — актуальна для логики промптов и
циклов, но хранилище задач с тех пор перешло на SQLite).
